# ADR-001: Целевой backend и модель запуска GRUZLI

- Статус: заблокировано — требуется решение владельца
- Дата решения: не указана

## Контекст

В `main` frontend использует Supabase: клиент приложения, Supabase Auth, RPC, таблицы и Edge Functions. Demo mode ограничен dev-сборкой. Конфигурация `amvera.yaml` описывает статическую сборку веб-приложения и не подтверждает наличие Amvera/PostgreSQL backend.

Открытые PR #14 и #44 — предложения. Они не являются принятым решением и не считаются внедрённой архитектурой.

## Решения, требующие подтверждения

- Целевой production-backend: [Supabase / Amvera и PostgreSQL]
- Demo mode: [только разработка/демонстрация / также production]
- Реальная регистрация и вход: [нужны / не нужны]
- Восстановление пароля: [нужно / не нужно]
- Если выбран Amvera/PostgreSQL: [полная замена / поэтапная миграция]

## Последствия

До подтверждения этих пунктов не менять auth и backend-потоки, не объединять направления PR #14 и #44 и не планировать зависимые изменения как выбранную реализацию.

После решения задачи по auth, созданию заказа и откликам формулировать относительно утверждённого направления.

## Блокирующие условия и проверка

- До решения владельца изменения auth, backend-потоков и миграций заблокированы.
- После ответа владельца зафиксировать backend, demo policy, требования к регистрации, входу и восстановлению пароля, а для Amvera/PostgreSQL — объём миграции.
- После фиксации решения сверить документ с требованиями владельца и запускать существующие проверки проекта для последующих изменений: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
- Запись ADR не подтверждает production-развёртывание, состояние live-сервисов или применение миграций; эти вопросы требуют отдельной проверки.

## Ограничения

- Выбор backend и поведения demo mode является решением владельца и не выводится из открытых PR.
- PR #14 и #44 отражают предложения, а не внедрённое состояние `main`.
- Статус live-сервисов, production-секретов, учётных записей и применённых миграций не подтверждён.
