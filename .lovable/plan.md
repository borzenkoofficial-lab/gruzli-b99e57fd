# План: Электронные договоры с онлайн-подписанием

## Что добавим

Диспетчер сможет при создании заявки (или потом) приложить договор. Грузчик, откликнувшийся и принятый на заявку, увидит договор, подпишет его пальцем/мышью, и обе стороны получат подписанный PDF.

## Пользовательский поток

**Диспетчер:**
1. В создании заявки — переключатель «Требуется договор» (для особых заказов)
2. Выбирает шаблон договора (стандартный) или вводит свои условия (предмет работ, сумма, срок, ответственность)
3. Подписывает свою сторону один раз в профиле (сохранённая подпись)
4. Видит список подписанных/неподписанных договоров по заявке

**Грузчик:**
1. После принятия отклика появляется баннер «Подпишите договор»
2. Открывает экран договора → читает PDF превью → ставит галочку согласия → рисует подпись пальцем
3. Получает финальный PDF с обеими подписями (можно скачать/переслать)

## Технические детали

**База данных (миграция):**
- `contract_templates` — шаблоны договоров диспетчера (name, body_template, dispatcher_id)
- `job_contracts` — экземпляр договора для заявки (job_id, dispatcher_id, terms jsonb, dispatcher_signature_url, status)
- `contract_signatures` — подписи грузчиков (contract_id, worker_id, signature_url, signed_at, signed_pdf_url, ip_address, user_agent)
- `jobs.requires_contract boolean default false`
- RLS: диспетчер видит свои, грузчик — только договоры заявок где он принят
- Storage bucket `contracts` (приватный) для PDF и подписей

**Edge function `generate-contract-pdf`:**
- Принимает contract_id + signature data
- Генерирует PDF через `pdf-lib` (Deno-совместимая библиотека)
- Встраивает обе подписи как изображения
- Загружает в bucket `contracts/{contract_id}/{worker_id}.pdf`
- Возвращает signed URL

**Frontend:**
- `src/components/ContractSignaturePad.tsx` — холст для подписи (react-signature-canvas или нативный canvas)
- `src/components/ContractViewer.tsx` — просмотр PDF (iframe + signed URL)
- `src/screens/ContractScreen.tsx` — экран подписания для грузчика
- В `CreateJobScreen` и `EditJobModal` — секция «Договор» с переключателем и редактором условий
- В `JobResponsesScreen` (диспетчер) — статус подписания у каждого принятого грузчика
- В `ProfileScreen` — раздел «Мои договоры» + сохранённая подпись диспетчера

**UI/Навигация:**
- Кнопка «Подписать договор» в карточке принятой заявки у грузчика
- Push-уведомление грузчику после accept_job_response, если requires_contract
- Уведомление диспетчеру когда грузчик подписал

## Что НЕ входит (можно добавить позже)
- Юридически значимая электронная подпись (КЭП) — это отдельная интеграция (Криптопро, Контур)
- Текущая реализация — простая графическая подпись + аудит-лог (ip, ua, timestamp), достаточная для внутренних соглашений
- Шаблоны договоров с произвольными переменными — пока один встроенный шаблон + редактируемые поля

## Шаги реализации

1. Миграция БД (таблицы, RLS, bucket)
2. Edge function для генерации PDF с подписями
3. Компонент ContractSignaturePad
4. Экран подписания для грузчика + интеграция в Index роутинг
5. UI диспетчера: переключатель в CreateJob/EditJob, статус в JobResponsesScreen
6. Раздел «Договоры» в профиле обоих ролей

Объём — крупный, около 8-10 файлов + миграция + edge function.
